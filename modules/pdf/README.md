# OFFYNEX PDF

A professional PDF management module.

## Planned Features
- Open and view PDF files
- Edit PDF text and content
- Merge and split PDF files
- Add, delete and reorder pages
- Compress PDF files
- Convert documents to PDF
- PDF forms and form filling
- Digital signatures
- Highlight and annotations
- OCR text recognition
- Password protection
- Print preview and printing
- Offline support

Status: Planned
