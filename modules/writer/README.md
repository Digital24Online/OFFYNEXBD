# OFFYNEX Writer

A professional word processing module.

## Planned Features
- Document creation and editing
- DOCX, ODT and PDF support
- Bengali and international fonts
- Tables, images and page layout
- Header and footer
- Page numbering
- Spell checking
- Print preview and printing
- Offline editing
- Auto save
- Keyboard shortcuts
- Advanced desktop toolbar
- Mobile editing toolbar
